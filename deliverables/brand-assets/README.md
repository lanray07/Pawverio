# Pawverio original asset package

The editable SVGs and matching PNGs are original procedural geometry authored for Pawverio. They contain no downloaded stock art, third-party icon pack or font outlines. SVG text remains editable and uses a system-font fallback. PNG typography was rendered with Windows Segoe UI. The separate `pawverio-companions.png` illustration was generated by the parent build workflow.

Master icon: calendar circle plus a paw, with a coral care check. Full-color master exports are 1024, 512 and 114 pixels. Adaptive foreground/background exports and a genuine single-color monochrome mark are separate. Dog/cat profiles, splash, onboarding, empty state and ten care/upgrade illustrations are included.

Run `python scripts/localization_brand_assets.py` to rebuild the procedural package and refresh SHA-256/file validation in `brand-assets-manifest.csv`. The contact sheet supports visual review. Amazon promotional art is name-only, 1024×500; the social banner is 1200×630. Store screenshots must come from actual app captures; these illustrations are not screenshots.

Device rendering, adaptive-icon masking and launcher display must still be tested. Vector availability does not mean every asset is wired into a live app screen. Check the app source and screenshot evidence before claiming integration. Review final artwork and copy before external publication.
