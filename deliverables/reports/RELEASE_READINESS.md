## Known limitations

WorkManager is inexact; quiet hours defer reminders; no exact delivery or universal Fire/voice support is promised. No cross-device household synchronization. Backups contain records only, excluding photos/documents, app settings/sitter preference contacts and purchase data, disclosed in UI; media needs separate export. JSON restore merges IDs and does not import filesystem paths. App-private Room/media rely on OS storage protection; optional app lock is not database encryption. Process-interrupted imports may leave private orphan files until later cleanup; logical deletion is not forensic erasure. Notification channel names follow manual app language selection or current device language in automatic mode. Store screenshot/listing drafts need human approval. No separate first-party analytics/crash collector, advertising, location tracking, hosted backend, website or automatic pet-record cloud uploader was added. The Amazon SDK contains reachable conditional diagnostics and API-use telemetry; no zero-telemetry claim applies to provider processes. The 39-row privacy questionnaire is Saved for review, not a legal/vendor certification. The current console has 13 description locales and nine dedicated artwork locales (72 uploaded images); four text-only locales use the default artwork fallback and remain unapproved.
